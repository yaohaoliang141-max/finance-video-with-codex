# 财经视频制作基于 Codex

一个面向中文财经内容创作者的 Codex 视频制作插件。它以 **HyperFrames + GSAP** 为渲染基础，把原始视频、口播稿或字幕制作成具有财经纪录片质感的 MG 动画视频。

项目重点不是简单地给视频叠加图表，而是让每一段动画与当前字幕在时间和语义上严格对应，并保留原视频、原声和原字幕。

## 核心功能

- **字幕强同步**：MG 动画绝不早于对应字幕出现，可在字幕出现后立即或稍晚触发。
- **强语义匹配**：金额、比例、流程、因果、账本和信用网络分别使用对应的可视化形式，拒绝只与大主题相关的泛化动画。
- **原素材保护**：默认保留原视频、原声音轨和已经烧录的字幕。
- **财经纪录片视觉**：黑灰底、暖白文字、橙色强调，结合档案纹理、金融素材和编辑式排版。
- **半透明图表**：柱状图、信息卡和数据层保持透明，让底层视频继续可见。
- **多样化构图**：交替使用左右布局、分屏、全屏、边缘锚定和非对称构图，避免整条视频像同一个模板反复换色。
- **镜像进退场**：动画怎么出现，就以对应的反向方式消失；不使用突然盖屏、闪切或无关硬转场。
- **章节进度条**：底部显示全片章节结构、当前章节和播放进度。
- **章节开场动画**：每章开始前生成 2–3 秒的编号章节页，包含中文章节名和可选英文副标题。
- **自动质检与渲染**：完成 HyperFrames 检查、布局检查、抽帧复核和最终 MP4 输出验证。

## 最重要的同步规则

假设字幕在 `01:12.400` 出现“10000元”：

1. `10000元` 数字动画只能在 `01:12.400` 或稍后出现。
2. 动画绝对不能提前预告该数字。
3. 动画可以比字幕稍晚消失，但不能与下一句字幕产生误导。
4. 可视化必须直接解释“10000元”在当前语境中的含义。

插件会在制作前建立字幕与 MG 的时间映射表，并拒绝使用均匀间隔或主题估算代替真实字幕时间戳。

## 工作流程

```text
原视频 / 稿件 / SRT / VTT
          │
          ▼
提取媒体参数与精确字幕时间
          │
          ▼
章节划分与字幕—MG映射表
          │
          ▼
HyperFrames + GSAP 动画制作
          │
          ▼
布局、时间、字幕安全区检查
          │
          ▼
MP4 渲染与抽帧复核
```

## 安装

### 从 Codex 插件界面安装

在 Codex 的插件页面选择从 GitHub 仓库添加插件，并使用：

```text
https://github.com/yaohaoliang141-max/finance-video-with-codex
```

插件依赖 HyperFrames。首次使用前，请确认 Codex 中已经安装并启用 HyperFrames 插件。

### 本地开发安装

```bash
git clone https://github.com/yaohaoliang141-max/finance-video-with-codex.git
```

将仓库作为本地 Codex 插件载入，重新打开 Codex 或开启新任务后即可调用其中的 Skill。

## 使用方式

安装后，在 Codex 中附上视频、口播稿或字幕，并调用：

```text
$subtitle-synced-finance-video
```

示例提示词：

```text
使用字幕强同步财经视频 Skill，把这个视频制作成财经纪录片风格。
保留原视频和字幕，MG 必须严格跟随字幕内容，完成后直接渲染成片。
```

## 输入与输出

支持的常见输入：

- MP4、MOV 等原始视频
- 中文口播稿
- SRT、VTT 或带时间戳的转写文件
- 已经烧录字幕的视频
- 章节划分、品牌色或动画参考图

默认输出：

- 1920×1080 MP4 成片
- 原音轨与原字幕
- 章节化 MG 动画
- 渲染参数与质检结果摘要

## 设计原则

1. 准确性优先于动画数量。
2. 同时字幕决定 MG 的内容与出现时间。
3. 可视化不能编造原稿中不存在的数据。
4. 版式可以变化，但整片视觉身份必须统一。
5. 章节系统帮助观众理解长视频结构，而不是遮挡内容。
